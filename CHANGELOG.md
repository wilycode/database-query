# Changelog

All notable changes to this package will be documented here.

## [0.1.0] - 2026-10-12

### Added

- Initial public release of the WilyCode SQL query builder.
- Canonical `CompiledQuery` with SQL, ordered parameters, and parameter types.
- Query statements, clauses, raw expressions, subqueries, and UNION support.
- Binder contracts for independent PDO and MySQLi driver packages.
- PHPUnit tests, GitHub Actions, and extended English documentation.
